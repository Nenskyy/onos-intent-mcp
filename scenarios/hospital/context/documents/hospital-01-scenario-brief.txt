INFRASTRUCTURE AND INTERPRETATION

All hosts use the 10.20.0.0/24 subnet. Switch links are s1-s2 and s2-s3.
Physical links and shared addressing do not grant permission to communicate.
Use the exact node names above when a tool requires Mininet node names.
Role descriptions refer to these nodes; no other endpoint is implied.
The word "server" alone does not uniquely identify an endpoint. There is no
default server or destination for an unspecified request.
No public Internet service, Wikipedia endpoint or Netflix endpoint is defined
by this hospital directory.

The directory describes intended identities, not current operational state.
Measure current connectivity rather than assuming it matches policy.
Ping tests demonstrate network reachability, not clinical measurement delivery,
alert application functionality, storage health or clinical safety.
